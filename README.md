__iCore - многофункциональное серверное программное обеспечение для *Minecraft: Pocket Edition* и *Minecraft:
Windows 10 Edition*.__
-------------

Некоторые функции, предлагаемые iCore:

* Расширенный API для плагинов.
* Возможность входа с версии 1.1.0 и 1.20.х.
* Частые обновления.
* Оптимизация.
* Разработчик готов выслушать ваше мнение.
